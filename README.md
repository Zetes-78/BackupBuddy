# Backup Buddy

Free, simple backups for Windows, by [Night Tech Solutions](https://nighttech.solutions/).

## Download

**[Download Backup Buddy for Windows](https://github.com/Zetes-78/BackupBuddy/releases/latest/download/BackupBuddy-Setup.exe)**

Requires Windows 10 (version 2004 or newer) or Windows 11, 64-bit.

## What it does

- You pick what to back up: Documents, Pictures and Desktop are on by default, plus any folders you add
- You pick where it goes: a USB drive, external hard drive, network folder or another drive
- Backups are ordinary files you can open without the app
- After the first backup, only new and changed files are copied
- Every copy is read back and checked against the original
- Earlier versions of changed files are kept for 30 days (adjustable)
- Optional automatic backups every day or once a week, with a reminder if the drive isn't plugged in
- Restoring never overwrites anything: files go into a new folder on your Desktop

Backup Buddy has no accounts, ads or tracking, and never sends your files anywhere except the location you choose.
